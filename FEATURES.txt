# Spring Boot Notification Microservice

## About the Project
This project sends notifications through email and SMS. It stores notification details, tracks whether messages are sent or failed, and allows failed notifications to be retried.

## Features

1. **REST API** – Create and view notifications.
2. **Database Storage** – Save notification details using Spring Data JPA and H2.
3. **Email Notifications** – Send emails using Gmail.
4. **SMS Notifications** – SMS sending code using Twilio (real account setup pending).
5. **Strategy Pattern** – Keep email and SMS sending logic separate.
6. **Background Sending** – Send notifications in the background using `@Async`.
7. **Input Validation** – Check email addresses and phone numbers before sending.
8. **Status Tracking** – Track notifications as `PENDING`, `SENT`, or `FAILED`.
9. **Failure Tracking** – Save error messages when sending fails.
10. **Automatic Retry** – Automatically retry failed notifications, up to 3 attempts.
11. **Resend Notification** – Manually resend failed notifications.
12. **Filter by Status** – Find notifications by their status.
13. **Pagination** – View notifications in smaller pages.
14. **Statistics** – See the total number of pending, sent, and failed notifications.
15. **Error Handling** – Return suitable error codes for invalid input, missing notifications, and invalid resend requests.
16. **Logging** – Show useful information in the console to help with debugging.
17. **Timeout Configuration** – Configure time limits for notification-related operations.

## Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- Gmail / Spring Mail
- Twilio (SMS integration code)

## How It Works

1. A user creates a notification through an API request.
2. The application checks the input.
3. The notification is saved in the database.
4. The application attempts to send the email or SMS.
5. The notification status is updated.
6. If sending fails, the error is saved and automatic retries can be attempted.
7. Users can view notifications, filter them, resend failed messages, and check statistics.

## Current Limitations

- SMS sending requires a configured Twilio account.
- The project currently uses the H2 database.
- Security and production deployment features are not yet implemented.

## Project Goal

The goal of this project is to learn Spring Boot by building a practical backend application with REST APIs, database storage, external integrations, background processing, and error handling.
